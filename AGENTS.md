# AGENTS.md

## Cursor Cloud specific instructions

### Overview

AGSVA Clearance Platform — a single-service Node.js application with a vanilla HTML/JS frontend and a lightweight server backed by embedded SQLite (`node:sqlite`). No build step, no bundler, no framework, zero npm runtime dependencies.

### Prerequisites

- **Node.js >= 22** (required for `node:sqlite` with `--experimental-sqlite`)
- System tools: `bash`, `curl`, `lsof`

### Quick reference

| Task | Command |
|---|---|
| Install devDependencies | `npm install` |
| Create env file | `cp .env.example .env` (if `.env` missing) |
| Full CI suite | `npm run ci` |
| Repo hygiene check | `npm run check:repo` |
| Server syntax check | `npm run check:server` |
| Shell syntax check | `npm run check:shell` |
| Smoke tests | `npm run test:smoke` |
| Start dev server | `node --experimental-sqlite server/local-app.mjs --host 0.0.0.0 --port 3000` |
| Start via script | `scripts/serve-index.sh start` |

### Running the server

The server requires the `--experimental-sqlite` flag. Start with:

```
LOCAL_APP_DEFAULT_FILE=index.html node --experimental-sqlite server/local-app.mjs --host 0.0.0.0 --port 3000
```

Use `--host 0.0.0.0` in Cloud Agent VMs so the browser can reach the server. The default `127.0.0.1` also works for API-only testing.

### Gotchas

- The server reads `.env` automatically on startup. If `.env` does not exist, create it from `.env.example` first.
- `firebase-config.js` is generated by `npm run build:firebase-config` (called by `check:server`). It is safe to run with placeholder `.env` values; the app falls back gracefully.
- Smoke tests (`npm run test:smoke`) start their own server on port 3311, so they do not conflict with a running dev server on port 3000.
- The only npm devDependency is `playwright` (optional, for future browser tests). The app itself runs without any installed packages.
- SQLite database is auto-created at `data/agsva-app.sqlite` on first server start.
- `artifacts/` and `data/` directories are gitignored runtime directories created automatically.
